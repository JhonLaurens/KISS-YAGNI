## Ejecutar la presentación

### 🎉 NUEVA VERSIÓN PREMIUM DISPONIBLE

Hay **2 versiones** de la presentación:

#### Opción 1: Ejecutar con Python
```bash
python start.py
```

Luego elige:
- **Versión actual**: `http://localhost:8000/src/web/index.html`
- **Versión premium** ⭐ (RECOMENDADA): `http://localhost:8000/src/web/index_premium.html`

#### Opción 2: Ejecutar con script (Windows)
```bash
ver_presentacion.bat
```

### ⚡ Diferencias entre versiones

| Característica | Versión Actual | Versión Premium ⭐ |

🎨 **Experiencia visual mejorada**

⚡ **Rendimiento optimizado**

## Controles de navegación

- **Flechas del teclado**: ← → ↑ ↓ para navegar
- **Botones**: Controles visuales en pantalla
- **Puntos de navegación**: Click directo a cualquier sección
- **Scroll**: Desliza con el ratón o trackpad
- **Touch**: Swipe en dispositivos táctiles
- **Home/End**: Ir al inicio o final
